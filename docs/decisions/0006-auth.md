# 0006: Authentication

Date: 2026-11-23. Status: accepted.

## Decision

Cloudflare Access sits in front of the UI and the engine API from the first deployment. The engine verifies the Access token on every request and records the signed-in identity on each approval or denial.

## Why

Aemeth exposes infrastructure details and can change infrastructure, so it is never deployed without authentication. Access needs no authentication code in the app and works for one user now and several later.

## Not decided

Roles, such as who may approve which gates, are added when there is more than one user.
